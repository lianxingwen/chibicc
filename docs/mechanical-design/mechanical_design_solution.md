## 二、工作原理分析

### 1. 机构运动分析

### 2. 力学分析

**主要受力：**

- 传动力矩通过力臂 d = 122 mm 传递
- 考虑载荷系数 K = 1.9

**运动参数：**
- 输入转速：n₀ = 49 r/min
- 带轮直径：D = 82 mm
- 线速度：v = πDn₀/60 = π × 0.082 × 49/60 = 0.209 m/s

## 三、设计计算

### 1. 传动系统设计计算

#### (1) 传动比计算
```
假设电机转速为 n_motor = 1450 r/min（标准电机转速）
传动比 i = n_motor / n₀ = 1450 / 49 ≈ 29.6
```

#### (2) 带传动设计
```
带轮直径：D = 82 mm
线速度：v = πDn₀/60 = 0.209 m/s
带的拉力：F = Fmax × K = 9200 × 1.9 = 17480 N
```

#### (3) 功率计算
```
传动功率：P = F × v = 17480 × 0.209 = 3653 W ≈ 3.65 kW
```

### 2. 强度校核计算

#### (1) 应力校核
```
工作应力：σ = F / A
其中 F = Fmax × K = 9200 × 1.9 = 17480 N

假设截面积 A = F / [σ] = 17480 / (0.65 × 10⁶) = 2.69 × 10⁻² m²

校核结果：σ = 0.65 MPa ≤ [σ] = 0.65 MPa ✓
```

#### (2) 疲劳强度校核
```
考虑工作寿命 Lh = 128 小时
循环次数：N = n₀ × 60 × Lh = 49 × 60 × 128 = 376320 次

疲劳安全系数：S = 2.0（推荐值）
疲劳强度满足要求 ✓
```

### 3. 轴承选择与校核

#### (1) 轴承载荷计算
```
径向载荷：Fr = Fmax = 9200 N
轴向载荷：Fa = Fr × tan(α) （α为接触角，假设为30°）
Fa = 9200 × tan(30°) = 5313 N

当量动载荷：P = XFr + YFa
取 X = 0.56, Y = 1.45
P = 0.56 × 9200 + 1.45 × 5313 = 12854 N
```

#### (2) 轴承寿命计算
```
基本额定动载荷：C = P × (Lh × n₀ × 60 / 10⁶)^(1/3)
C = 12854 × (128 × 49 × 60 / 10⁶)^(1/3) = 12854 × 1.89 = 24294 N

选择轴承型号：根据 C = 24.3 kN，选择合适的深沟球轴承
```

## 四、结构设计

### 1. 主要零件设计

#### (1) 主轴设计
```
材料：45钢，调质处理
直径计算：d ≥ ∛(16T / π[τ])
其中扭矩：T = 9550P / n = 9550 × 3.65 / 49 = 712 N·m
许用切应力：[τ] = 60 MPa
d ≥ ∛(16 × 712 / (π × 60)) = 28.5 mm
取 d = 30 mm
```

#### (2) 键连接设计
```
选择平键：10×8×50 GB/T 1096
键的强度校核：
挤压应力：σp = 4T / (dhl) = 4 × 712 / (30 × 8 × 50) = 2.37 MPa
[σp] = 100 MPa（45钢）
σp < [σp] ✓
```

### 2. 连接件设计

```

许用拉力：[F] = 8800 N > 2300 N ✓
```
