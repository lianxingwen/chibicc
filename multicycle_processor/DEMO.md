# 多周期处理器演示

## 演示程序说明

本处理器包含一个预设的测试程序，演示了多种MIPS指令的执行。

### 测试程序（汇编代码）

```assembly
# 程序开始
add  $1, $0, $0     # $1 = 0 + 0 = 0
addi $1, $1, 5      # $1 = 0 + 5 = 5
addi $2, $0, 3      # $2 = 0 + 3 = 3
add  $3, $1, $2     # $3 = 5 + 3 = 8
sub  $4, $3, $2     # $4 = 8 - 3 = 5
beq  $1, $4, 2      # if $1 == $4 (5 == 5), jump 2 instructions
addi $5, $0, 10     # $5 = 10 (这条指令被跳过)
addi $6, $0, 20     # $6 = 20 (这条指令被跳过)
addi $7, $0, 100    # $7 = 100 (跳转到这里)
```

### 机器码（十六进制）

```
地址    机器码      指令
0x00:   0x00000820  add  $1, $0, $0
0x04:   0x20210005  addi $1, $1, 5
0x08:   0x20020003  addi $2, $0, 3
0x0C:   0x00221820  add  $3, $1, $2
0x10:   0x00622022  sub  $4, $3, $2
0x14:   0x10240002  beq  $1, $4, 2
0x18:   0x2005000A  addi $5, $0, 10  (跳过)
0x1C:   0x20060014  addi $6, $0, 20  (跳过)
0x20:   0x20070064  addi $7, $0, 100
```

## 执行流程

### 第1条指令：add $1, $0, $0
- **周期1-2**: 取指令，译码
- **周期3**: 执行加法运算
- **周期4**: 写回结果到$1
- **结果**: $1 = 0

### 第2条指令：addi $1, $1, 5
- **周期5-6**: 取指令，译码
- **周期7**: 执行立即数加法
- **周期8**: 写回结果到$1
- **结果**: $1 = 5

### 第3条指令：addi $2, $0, 3
- **周期9-10**: 取指令，译码
- **周期11**: 执行立即数加法
- **周期12**: 写回结果到$2
- **结果**: $2 = 3

### 第4条指令：add $3, $1, $2
- **周期13-14**: 取指令，译码
- **周期15**: 执行加法运算
- **周期16**: 写回结果到$3
- **结果**: $3 = 8

### 第5条指令：sub $4, $3, $2
- **周期17-18**: 取指令，译码
- **周期19**: 执行减法运算
- **周期20**: 写回结果到$4
- **结果**: $4 = 5

### 第6条指令：beq $1, $4, 2
- **周期21-22**: 取指令，译码
- **周期23**: 比较$1和$4，计算跳转地址
- **结果**: $1 == $4 (5 == 5)，跳转成功
- **PC更新**: PC = PC + 4 + (2 << 2) = 0x14 + 4 + 8 = 0x20

### 跳过的指令
- 0x18: addi $5, $0, 10 (被跳过)
- 0x1C: addi $6, $0, 20 (被跳过)

### 第7条指令：addi $7, $0, 100
- **周期24-25**: 取指令，译码
- **周期26**: 执行立即数加法
- **周期27**: 写回结果到$7
- **结果**: $7 = 100

## 最终寄存器状态

| 寄存器 | 值  | 说明 |
|--------|-----|------|
| $0     | 0   | 硬件固定为0 |
| $1     | 5   | addi $1, $1, 5 |
| $2     | 3   | addi $2, $0, 3 |
| $3     | 8   | add $3, $1, $2 |
| $4     | 5   | sub $4, $3, $2 |
| $5     | 0   | 被分支跳过 |
| $6     | 0   | 被分支跳过 |
| $7     | 100 | addi $7, $0, 100 |

## 性能分析

- **总指令数**: 7条（2条被跳过）
- **总周期数**: 约27个时钟周期
- **平均CPI**: 约3.86（27÷7）
- **分支预测**: 100%正确（1/1）

## 支持的指令类型

### R型指令
- **ADD**: 加法
- **SUB**: 减法
- **AND**: 按位与
- **OR**: 按位或
- **SLT**: 小于则置位

### I型指令
- **ADDI**: 立即数加法
- **LW**: 加载字
- **SW**: 存储字
- **BEQ**: 相等则分支

### J型指令
- **J**: 无条件跳转
