# GTKWave操作流程图

## 🎯 第一步：找到信号树
```
左侧窗口应该显示：
┌─────────────────┐
│ SST             │
│ ▶ testbench     │ ← 点击这个三角形
│                 │
└─────────────────┘
```

## 🎯 第二步：展开testbench
```
点击后变成：
┌─────────────────┐
│ SST             │
│ ▼ testbench     │
│   ├── clk       │ ← 双击添加
│   ├── reset     │ ← 双击添加  
│   └── ▶ cpu     │ ← 点击展开
└─────────────────┘
```

## 🎯 第三步：展开cpu模块
```
┌─────────────────┐
│ SST             │
│ ▼ testbench     │
│   ├── clk       │
│   ├── reset     │
│   └── ▼ cpu     │
│       ├── ▶ ctrl_unit │ ← 点击展开
│       └── ▶ dp       │ ← 点击展开
└─────────────────┘
```

## 🎯 第四步：添加关键信号
```
展开dp后：
┌─────────────────┐
│ ▼ dp            │
│   ├── pc        │ ← 双击添加
│   ├── instruction │ ← 双击添加
│   └── ▶ reg_file_inst │
└─────────────────┘

展开ctrl_unit后：
┌─────────────────┐
│ ▼ ctrl_unit     │
│   └── state     │ ← 双击添加
└─────────────────┘
```

## 🎯 第五步：查看波形
```
右侧应该显示：
┌─────────────────────────────────────┐
│ Signals  │ Waves                    │
│ clk      │ ┌─┐ ┌─┐ ┌─┐ ┌─┐         │
│          │ │ │ │ │ │ │ │ │         │
│          │ ┘ └─┘ └─┘ └─┘ └─         │
│ reset    │ ┌───┐                    │
│          │ │   └────────────────    │
│ pc       │ 00000000→00000004→...    │
│ instruction │ 20010005→20020003→... │
│ state    │ 000→001→010→011→000→...  │
└─────────────────────────────────────┘
```

## ⚠️ 如果右侧是黑色的

### 原因1：没有添加信号
- **解决**：双击左侧的信号名

### 原因2：时间范围不对  
- **解决**：点击工具栏的 🔍 "Zoom Fit" 按钮

### 原因3：VCD文件有问题
- **解决**：重新运行仿真
```bash
vvp multicycle_processor
```

## 🎨 美化技巧

### 改变数字显示格式：
1. 右键点击信号名
2. 选择 "Data Format"
3. 选择：
   - **Hex** - 十六进制 (推荐用于pc, instruction)
   - **Decimal** - 十进制 (推荐用于寄存器值)
   - **Binary** - 二进制 (推荐用于state)

### 调整信号顺序：
- 拖拽左侧的信号名上下移动

### 添加注释：
- 右键空白处 → Insert → Comment

## 🔍 重要检查点

看到这些就说明正常：
✅ clk有规律跳变  
✅ reset开始是高，后来变低
✅ pc从0开始，每次增加4
✅ instruction在变化
✅ state在000→001→010→011循环

## 📞 如果还是有问题

请检查：
1. 仿真输出是否正常（应该有文字输出）
2. VCD文件大小是否大于0
3. 是否在正确的目录中运行

按照这个流程，您应该能看到完整的波形图了！
