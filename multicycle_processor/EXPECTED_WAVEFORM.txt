关键执行阶段:
==============

阶段1 (20-120ns): 执行 addi $1, $0, 5
  - 取指: PC=0, instruction=20010005
  - 译码: 识别为I型指令，立即数=5
  - 执行: ALU计算 0 + 5 = 5  
  - 写回: $1 = 5

阶段2 (120-220ns): 执行 addi $2, $0, 3
  - 取指: PC=4, instruction=20020003
  - 译码: 识别为I型指令，立即数=3
  - 执行: ALU计算 0 + 3 = 3
  - 写回: $2 = 3

阶段3 (220-320ns): 执行 add $3, $1, $2  
  - 取指: PC=8, instruction=00221820
  - 译码: 识别为R型指令
  - 执行: ALU计算 5 + 3 = 8
  - 写回: $3 = 8

阶段4 (320-420ns): 执行 sub $4, $3, $2
  - 取指: PC=12, instruction=00622022  
  - 译码: 识别为R型指令
  - 执行: ALU计算 8 - 3 = 5
  - 写回: $4 = 5

阶段5 (420-520ns): 执行 beq $1, $2, 1
  - 取指: PC=16, instruction=10220001
  - 译码: 识别为分支指令
  - 执行: 比较 $1(5) != $2(3)，分支不成功
  - 写回: PC = PC + 4 = 20

阶段6 (520-620ns): 执行 addi $7, $0, 100
  - 取指: PC=32, instruction=20070064
  - 译码: 识别为I型指令，立即数=100
  - 执行: ALU计算 0 + 100 = 100
  - 写回: $7 = 100
