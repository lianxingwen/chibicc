# GTKWave波形图查看指南

## 🎯 正确的波形图应该显示什么

### 预期的波形信号和模式

#### 1. 时钟信号 (clk)
```
clk: ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐
     │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │
     ┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─
```
- **特征**: 规律的方波，每10ns一个周期
- **作用**: 驱动整个处理器运行

#### 2. 复位信号 (reset)
```
reset: ┌─────┐
       │     │
       │     └─────────────────────────
       0    20ns
```
- **特征**: 开始时为高电平，20ns后变为低电平
- **作用**: 初始化处理器状态

#### 3. 程序计数器 (pc)
```
pc: 00000000 → 00000004 → 00000008 → 0000000C → 00000010 → 00000020
    ────────   ────────   ────────   ────────   ────────   ────────
```
- **特征**: 每执行完一条指令后递增4
- **注意**: 在分支指令时会跳转到0x20

#### 4. 指令 (instruction)
```
instruction: 20010005 → 20020003 → 00221820 → 00622022 → 10220001 → 20070064
            ────────   ────────   ────────   ────────   ────────   ────────
```
- **20010005**: addi $1, $0, 5
- **20020003**: addi $2, $0, 3  
- **00221820**: add $3, $1, $2
- **00622022**: sub $4, $3, $2
- **10220001**: beq $1, $2, 1 (分支不成功)
- **20070064**: addi $7, $0, 100

#### 5. 控制状态 (state)
```
state: 000 → 001 → 010 → 011 → 000 → 001 → 010 → 011 → 000 → ...
       ───   ───   ───   ───   ───   ───   ───   ───   ───
```
- **000**: 取指令 (Fetch)
- **001**: 译码 (Decode) 
- **010**: 执行 (Execute)
- **011**: 写回 (Writeback)

## 📋 GTKWave操作步骤

### 第一步：打开信号树
1. 在左侧 **SST** 窗口中，点击 `testbench` 前的 **▶** 展开
2. 您应该看到：
   ```
   ▼ testbench
     ├── clk
     ├── reset  
     └── ▶ cpu
   ```

### 第二步：添加基本信号
**双击以下信号添加到波形图**：
1. `clk` - 时钟信号
2. `reset` - 复位信号

### 第三步：展开处理器模块
1. 点击 `cpu` 前的 **▶** 展开
2. 您应该看到：
   ```
   ▼ cpu
     ├── ▶ ctrl_unit
     └── ▶ dp
   ```

### 第四步：添加数据通路信号
1. 点击 `dp` 前的 **▶** 展开
2. **双击添加**：
   - `pc` - 程序计数器
   - `instruction` - 当前指令

### 第五步：添加控制信号
1. 点击 `ctrl_unit` 前的 **▶** 展开  
2. **双击添加**：
   - `state` - 控制状态

### 第六步：添加寄存器信号（可选）
1. 展开 `dp` → `reg_file_inst`
2. 添加感兴趣的寄存器：
   - `registers[1]` - $1寄存器
   - `registers[2]` - $2寄存器
   - `registers[3]` - $3寄存器

## 🔍 波形分析要点

### 正常执行的特征：
1. **时钟规律跳变** - 每10ns一次
2. **复位后开始执行** - reset变低后，pc开始变化
3. **状态循环** - 每条指令都经历 000→001→010→011 的状态转换
4. **PC递增** - 大部分时候PC每次增加4
5. **指令变化** - instruction随着PC变化而变化

### 关键时间点：
- **0-20ns**: 复位阶段
- **20-120ns**: 执行第一条指令 (addi $1, $0, 5)
- **120-220ns**: 执行第二条指令 (addi $2, $0, 3)
- **220-320ns**: 执行第三条指令 (add $3, $1, $2)
- **320-420ns**: 执行第四条指令 (sub $4, $3, $2)
- **420-520ns**: 执行分支指令 (beq)
- **520-620ns**: 执行跳转后的指令

## ⚠️ 常见问题

### 如果波形是空的：
1. 确认左侧有信号列表
2. 双击信号名添加到右侧
3. 检查时间范围（应该是0-1000ns）

### 如果信号显示不正确：
1. 重新编译：`iverilog -o multicycle_processor *.v`
2. 重新仿真：`vvp multicycle_processor`
3. 重新打开VCD文件

### 如果看不到信号变化：
1. 检查时间轴范围
2. 使用 **Zoom Fit** 按钮自动调整
3. 确认仿真时间足够长（1000ns）

## 🎨 美化波形显示

1. **调整信号顺序**: 拖拽信号名重新排列
2. **改变显示格式**: 右键信号 → Data Format
   - Binary: 二进制显示
   - Hex: 十六进制显示  
   - Decimal: 十进制显示
3. **添加分隔线**: Insert → Comment 添加注释分隔
