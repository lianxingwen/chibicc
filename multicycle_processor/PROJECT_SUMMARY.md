# 多周期处理器项目总结

## 项目概述

本项目实现了一个完整的多周期MIPS处理器，使用Verilog硬件描述语言编写，支持在Windows和Linux环境下运行。

## 技术特点

### 1. 多周期设计
- 每条指令分多个时钟周期执行
- 状态机控制指令执行流程
- 资源复用，降低硬件成本

### 2. 完整的MIPS子集
- 支持R型、I型、J型指令
- 实现了基本的算术、逻辑、分支、跳转操作
- 32位数据通路设计

### 3. 模块化设计
- ALU（算术逻辑单元）
- 寄存器文件（32个32位寄存器）
- 存储器（统一指令/数据存储）
- 控制单元（有限状态机）
- 数据通路（连接各组件）

## 支持的指令集

| 类型 | 指令 | 操作码 | 功能 |
|------|------|--------|------|
| R型  | ADD  | 000000 | 寄存器加法 |
| R型  | SUB  | 000000 | 寄存器减法 |
| R型  | AND  | 000000 | 按位与 |
| R型  | OR   | 000000 | 按位或 |
| R型  | SLT  | 000000 | 小于则置位 |
| I型  | ADDI | 001000 | 立即数加法 |
| I型  | LW   | 100011 | 加载字 |
| I型  | SW   | 101011 | 存储字 |
| I型  | BEQ  | 000100 | 相等则分支 |
| J型  | J    | 000010 | 无条件跳转 |

## 状态机设计

处理器使用12个状态的有限状态机：

1. **FETCH** - 取指令
2. **DECODE** - 指令译码
3. **MEMADR** - 存储器地址计算
4. **MEMREAD** - 存储器读取
5. **MEMWB** - 存储器写回
6. **MEMWRITE** - 存储器写入
7. **EXECUTE** - R型指令执行
8. **ALUWRITEBACK** - ALU结果写回
9. **BRANCH** - 分支处理
10. **ADDIEXECUTE** - 立即数指令执行
11. **ADDIWRITEBACK** - 立即数结果写回
12. **JUMP** - 跳转处理
